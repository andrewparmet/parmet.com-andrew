## GitHub

[My GitHub account.](https://github.com/andrewparmet)

Some highlights:

[Protokt](https://github.com/open-toast/protokt): A [Protocol Buffer](https://developers.google.com/protocol-buffers) compiler and runtime for Kotlin.

[Buf Gradle Plugin](https://github.com/andrewparmet/buf-gradle-plugin): A Gradle plugin for the [Buf](https://buf.build/) Protocol Buffers tool.

[Squash lambdas](https://github.com/andrewparmet/squash-lambdas): Automated management for squash reservations made through the Club Locker platform.

[Risk board game simulation](https://github.com/andrewparmet/risk-calc): Simulate battles between armies of various sizes, allowing for the novel possibility of the defending army dynamically choosing its number of defenders to attempt to optimize its chances of successful defense.

[MySQL-to-H2](https://github.com/andrewparmet/mysql2h2-converter): A library to convert MySQL scripts to their closest equivalent [H2 Database](http://www.h2database.com/html/main.html) form, useful for testing. Forked from an older and mostly-complete effort.
